> この検証で見落とし（抗ヒスタミン重複）と過剰警告（防腐剤）の両方を発見・修正した。
> 別の商品を試す場合は以下の手順で。

これまでのテストはHTMLから生成した綺麗な成分表示画像で行っており、実物のパッケージ（光沢・曲面・小さい文字・照明のムラ）では結果が変わりうる。

### 用意するもの
- 手持ちの**市販薬**を1つ（鎮痛薬・胃薬など何でも）
- 手持ちの**化粧水か乳液**を1つ

### 手順
1. スマホで https://overlai-delta.vercel.app/ を開く
2. 下部中央のスキャンボタン → カメラが起動
3. **パッケージの成分表示**（「成分・分量」「全成分」の欄）を枠に入れて撮影
4. 判定が出るまで待つ（9〜11秒）
5. **「根拠を見る」を開いて、読み取られた成分名が正しいか確認する**

### 確認すること

| 項目 | 見るところ |
| :--- | :--- |
| 成分名が正確か | 判定カード上部の成分タグ。誤字（「いブプロフェン」など）が無いか |
| 商品名が合っているか | 成分タグの上 |
| 判定が納得できるか | 色・見出し・要約 |
| 所要時間 | カード下部に「判定にかかった時間 ◯秒」が出る |

### 失敗したときの対処

| 症状 | 対処 |
| :--- | :--- |
| 「成分表示を読み取れませんでした」（422） | 明るい場所で、成分表示に**寄って**撮り直す。影と光の反射を避ける |
| 成分名が一部間違っている | 別の角度・距離で再撮影。それでもダメなら、その商品はデモに使わない |
| ボトルの曲面で読めない | ラベルの平らな部分を正面から。箱があれば箱の成分表示を撮る |
| どうしても通らない | `?demo=` のモックに切り替えて撮影する（§D） |

**デモ動画には、ここで確実に読み取れた商品だけを使うこと。**

## C. デモの通しリハーサル（15分）

**本番と同じ流れを、録画せずに一度通す。**

```
マイストック（家にあるものが並んでいる）
   ↓ スキャンボタン
カメラ起動 → 成分表示を撮影
   ↓ 「成分を読み取っています」→「家の在庫と照合しています」
判定カード（色・見出し・要約）
   ↓ 「根拠を見る」
判定理由（成分名つき）
```

- **🟡と🔴の2本**を通す（企画の半分ずつを担っているため）
- 待ち時間（9〜11秒）が思ったより長く感じるかを体感しておく
- 通し終わったら、**同じ流れで1本録画してみる**（本番前に必ず1本撮っておく）

### 在庫が判定を変えることを見せるカット

**このアプリの主張が一番はっきり映る流れ。** 商品側のDBで戦う既存アプリには原理的にできない。

```
百草丸をスキャン         → 🔵 買っても問題なさそう
   ↓ ストックを追加
百草丸をスキャン（同じ商品）→ 🟡 家にあります
   ↓ 百草丸をタップ → 削除する → 確認 → 削除する
百草丸をスキャン（同じ商品）→ 🔵 に戻る
```

商品は一度も変えていない。**変えたのは家の在庫だけ。**

### B. の UI 確認に足すこと

- マイストックで**カテゴリ見出しをタップ**して開閉する（品名の要約が残ること）
- スキャン画面へ行って戻り、**閉じた状態が保たれている**こと
- **項目をタップ**して操作シートが上がること。「削除する」→ 確認 →「やめる」で消えないこと
- 編集モード（ヘッダーの「編集」）でも同じ操作ができ、タップの導線と競合しないこと
