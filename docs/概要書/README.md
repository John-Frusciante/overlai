# 作品概要書のソース

編集用PPTX：[`../Overlai_作品概要書.pptx`](../Overlai_作品概要書.pptx)（16:9横・5ページ）  
提出用PDF：[`../Overlai_作品概要書.pdf`](../Overlai_作品概要書.pdf)（PowerPointから書き出し）

現在の提出物はPPTXを原本とします。`overview.tpl.html` と `overview.html` は、再構成前の比較資料として残しています。

## 構成

| ページ | 伝えること |
| :---: | :--- |
| 1 | 井上の「風邪薬の重複」と、杉本・濱田の「ステロイド外用薬と化粧品の相性・塗る順番」という原体験 |
| 2 | 薬と化粧品を一つの在庫にまとめ、店頭の商品と照合する解決策 |
| 3 | 在庫登録から店頭での判定、購入後のルーティンまでの利用の流れ |
| 4 | 同じ御岳百草丸でも、家の在庫によって判定が変わる実証 |
| 5 | 二段階のAI、ルールによる固定処理、出典・裏取り・相談推奨などの安全設計 |

審査員がアプリを知らない状態でも、原体験から価値、利用場面、独自性、安全性までを2〜3分で追える順序にしています。

## 使用素材

- `stock-s.png`：在庫画面
- `reasonfull-s.png`：判定理由画面
- `routine-s.png`：ルーティン画面
- `qr.svg`：公開URL（https://overlai-delta.vercel.app）のQRコード

画面仕様が変わった場合は、PPTX内のスクリーンショットも更新してください。QRコードは公開URLが変わった場合のみ作り直します。
