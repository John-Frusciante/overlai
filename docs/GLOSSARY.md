# 用語集

このプロジェクトは医薬品・化粧品の領域に踏み込むため、コードとドキュメントに専門用語が出てくる。**知らないまま実装すると判定ロジックを壊す**ので、ここで押さえておく。

---

## プロジェクト固有の用語

| 用語 | 意味 |
| :--- | :--- |
| **ストック** | ユーザーの自宅にある薬・コスメ・バス用品。**判定の基準となるデータ**。`StockItem` |
| **スキャン** | 店頭商品のパッケージを撮影し、AIに成分を解釈させる操作 |
| **判定 / Judgement** | スキャン結果とストック全件を突合して得られる3色シグナルと根拠 |
| **シグナル** | 🔵 blue（買ってよい）／🟡 yellow（家にある）／🔴 red（注意） |
| **ステップ1 / 抽出** | 画像 → 成分の構造化（Vision）。`ExtractionResult` |
| **ステップ2 / 照合** | 抽出結果＋在庫 → 判定。`Judgement` |
| **インバス** | 風呂の中で使うもの。シャンプー・トリートメント・洗顔・ボディソープ |
| **アウトバス** | 風呂上がりに使うもの。化粧水・美容液・乳液・クリーム・外用薬 |
| **モックモード** | APIキーなしで固定応答を返す動作モード。**AIは動いていない**。現在は使っていないが、デモ当日の障害時の保険として残してある |
| **プロバイダ** | どのAIを使うか。Anthropic Claude / Azure OpenAI / モックの3つ。`lib/llm.ts` が環境変数から決める |

## 医薬品の用語

| 用語 | 意味 | なぜ重要か |
| :--- | :--- | :--- |
| **処方薬** | 医師の処方箋にもとづいて薬局で受け取る薬 | **判定の🔴条件の中心**。処方薬が絡むかどうかで🟡と🔴が分かれる |
| **市販薬（OTC）** | 処方箋なしで買える薬 | 市販品どうしの重複は🟡（買う必要がない） |
| **内服薬** | 飲む薬 | 成分の重複は過量摂取につながる |
| **外用薬** | 塗る・貼る薬。軟膏・クリーム・ローションなど | **企画の核心**。医療の側からは「外用薬」、生活の側からは「肌に塗るもの」で、どちらの産業も見に行かない空白地帯 |
| **NSAIDs** | 非ステロイド性抗炎症薬。イブプロフェン、ロキソプロフェン等 | **同系統を重ねると過量摂取のリスク**。シードに処方NSAIDsを置いてはならない理由（DEVELOPMENT.md §5.1） |
| **ステロイド外用薬** | 炎症を抑える塗り薬。ベタメタゾン吉草酸エステル等 | 使用中の肌はバリア機能が落ちている場合があり、刺激成分との併用が🔴の代表例 |
| **ヘパリン類似物質** | 保湿を目的とする外用薬（ヒルドイド等） | 処方薬だが薬効は保湿。塗る順序では「薬を塗る前の土台」に位置する |
| **抗ヒスタミン薬** | アレルギー症状を抑える薬。フェキソフェナジン等 | シードの `stk-001`。NSAIDsを避けるために選んだ |
| **剤形** | 薬や化粧品の形状。錠剤・軟膏・クリーム・ローション等 | **塗る順序のソートキー**。`ItemForm` |
| **基剤** | 有効成分を運ぶ土台。油性か水性かで浸透と重ね順が変わる | 剤形と併せて順序を決める |
| **添付文書** | 医薬品の公式な情報文書。PMDAが公開 | 内服薬の相互作用はここに明記されている。**外用薬×化粧品は存在しない** |
| **PMDA** | 医薬品医療機器総合機構 | 医薬品情報の公式な出所 |
| **JAHIS** | 保健医療福祉情報システム工業会。調剤明細のQRコード規格 | 処方薬の一括登録に使える規格。本デモでは未実装 |
| **吸収阻害** | ある成分が別の薬の吸収を妨げ、効きを弱めること。鉄・カルシウム × 抗菌薬が代表例。**副作用ではなく「効かない」だけなので気づきにくい** |
| **ニューキノロン系／テトラサイクリン系** | 抗菌薬の系統。金属イオン（鉄・カルシウム等）と結合して吸収が落ちる |
| **アドヒアランス** | 患者が治療方針を理解して継続できているか | 「薬より正しく使えているかがボトルネック」という企画書の主張の背景 |

## 化粧品の用語

| 用語 | 意味 | なぜ重要か |
| :--- | :--- | :--- |
| **全成分表示** | 化粧品に義務づけられた成分の記載。**配合量の多い順** | 順序に意味があるため、抽出時に**記載順を保持する** |
| **JANコード** | 商品のバーコード | **化粧品のJAN→全成分の公式DBは日本に存在しない**。バーコードではなく成分表示を直接読む理由 |
| **ナイアシンアミド** | ビタミンB3誘導体。美容成分 | シードの美容液の主成分。重複判定の例に使う |
| **レチノール** | ビタミンA誘導体 | 高濃度ビタミンCやAHA/BHAと重ねると刺激になる可能性（成分バッティング） |
| **AHA / BHA** | 角質ケア成分。グリコール酸（AHA）、サリチル酸（BHA） | 酸性度が高く、他の刺激成分と重なると負担になりうる |
| **エタノール** | 溶剤・清涼感を出す成分 | ステロイド外用中の肌への刺激リスクの代表例（🔴シナリオ） |
| **洗浄基剤** | 洗浄成分の系統 | 企画書 #13 の判定対象。**未実装** |
| ├ アミノ酸系 | ココイルグルタミン酸TEA等。低刺激・洗浄力はおだやか | シードのシャンプー |
| ├ 高級アルコール系 | ラウレス硫酸Na等。洗浄力が強い | 🔵判定の例（ワックス落とし用） |
| └ 石鹸系 | 脂肪酸ナトリウム等。さっぱりするがアルカリ性 | — |
| **酸化目安** | 開封後に品質が変わりはじめるおおよその期間 | オイル・美容液は3ヶ月、化粧水類は6ヶ月として実装（`lib/expiry.ts`） |

## 技術用語

| 用語 | 意味 |
| :--- | :--- |
| **構造化出力** | スキーマを渡してAIの出力形式を強制する仕組み。JSONパース失敗が原理的に起こらない。Anthropic は `output_config.format`、OpenAI は `response_format` |
| **adaptive thinking** | Claude が必要に応じて思考する既定の動作。**無効化しない**（DEVELOPMENT.md §5.4）。Anthropic 経路でのみ関係する |
| **effort** | 思考の深さとトークン消費のつまみ。`low`〜`max`。既定は `high` |
| **Route Handler** | Next.js App Router のサーバー側エンドポイント。**APIキーを保持できる唯一の場所** |
| **Vision** | 画像を入力として受け取るAIの機能 |
| **PWA** | ホーム画面に追加して全画面起動できるWebアプリの仕組み |
| **Azure OpenAI 互換プロキシ** | 学校配布のエンドポイント。標準の `openai` SDK に `baseURL` を渡して使う。現在の稼働環境 |
| **`max_completion_tokens`** | 出力トークンの上限。**gpt-5 系は `max_tokens` を受け付けず、これを使う**。Anthropic は `max_tokens` |
| **json_schema (strict)** | OpenAI の構造化出力。zod スキーマから生成し、出力形式を強制する。プロキシでも通ることを実測で確認済み |

## 薬機法まわりで気をつけること

コードとUIの文言は以下を守る（[設計仕様書 §12](設計仕様書_Overlai_デモ版.md)）。

- **診断・治療判断を行わない。** 疾患名の推定、用法用量の指示をしない
- **断定しない。** 「〜の可能性があります」で統一する
- **根拠を示す。** 判定理由に必ず成分名を含める
- **専門家導線を常設する。** 全判定色で「薬剤師・皮膚科に相談」を表示する
- **医療機器に該当させない。** 記録と情報提示の範囲に留める
