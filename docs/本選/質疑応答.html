2026年10月11日（日）13:00〜17:00・日経カンファレンスルーム。ブース展示と1分ピッチの公開審査。答えはすべてリポジトリの記録と実測にもとづく。「要確認」の印が付いた質問だけは、自分たちの事実に合わせて今夜のうちに直しておく。

どの質問にも通す5つの芯

  1. 判定の基準は、商品ではなく「その人の家の在庫」。同じ商品でも、在庫が違えば判定が変わる（御岳百草丸：青 → 在庫に入れると黄）。
  2. きっかけは自分たちの困りごと。井上は風邪薬を買って帰ったら似た薬が家にあった。濱田・杉本は処方薬を使う肌に、化粧水を使っていいのか、どちらが先かで迷った。
  3. AIの答えをそのまま出さない。成分が実在するか、組み合わせが出典つきの表にあるかをサーバーで確かめ、出典を付けてから見せる。
  4. 安全に関わることはAIに任せない。断定しない。赤のときの相談の案内はサーバーが必ず出す。診断はしない。
  5. できないことは先に言う。知識の表は代表例で網羅ではない。最後に判断するのは薬剤師・医師。

答え方と、口にしないこと

答え方の型

  1. 結論を一文で言う（「はい」「いいえ」「3つあります」）
  2. 理由を1つか2つ
  3. 実例か数字を1つ（できれば画面を見せる）
  4. 限界があれば自分から添える

答えに詰まったら

  • 「そこはまだ確かめられていません。いま確かめられているのは〜までです」
  • 「いい質問です。いまの実装では〜で、次に手を入れるならそこだと考えています」
  • 技術の細部は井上に振る／エピソードは本人が話す

口にしないこと

  • 「安全です」「大丈夫です」「診断します」などの断定
  • 「精度は〇％です」（測っていない数字）
  • 「すべての飲み合わせを網羅しています」
  • 「AIが塗る順番を決めます」（順番はルール。AIが書くのは一言だけ）
  • 「医療機器には当たらないと確認済みです」（確認は事業化の前にやること）
  • 固定応答（?demo=）の画面を「AIの判定です」と言うこと
  • 企画書の「8回分残っていた」の場面を実話として話すこと
