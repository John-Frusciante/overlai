## 2. ブースを開ける前・来場者ごとにやること

**開ける前（12:30ごろ）**

1. 本番URLを開き、ホーム画面のアイコンから起動する（PWA）
2. **Vercel の環境変数に `GUARD_MAX_REQUESTS=120` を入れて再デプロイする。** 入口の回数制限は「同じ相手から10分に30回」で、会場では全端末が同じ相手に見えるため
3. 1回スキャンして、判定まで通ることを確かめる（関数を起こしておく意味もある）

**来場者が替わるたび**

- **マイストックの見出し「マイストック」を1.2秒長押し → 「戻す」。** 在庫・服薬記録・肌質などがすべて見本に戻る
- 前の人が触った在庫が残っていると、次の人に見せる判定が変わる。**このアプリは在庫で判定が変わるので、必ず戻す**

## 3. デモの流れ（1人あたり2〜3分）

ピッチの台本と同じ順番にしてある。来場者の興味に合わせて ③ か ④ を選んでよい。

### ① 家にあるものを見せる（10秒）

マイストックを見せる。

> 「家にある薬や化粧品を登録しておくアプリです。いま見本で11件入っています」

### ② 🟡 を出す（20秒）

**カロナールA** の成分表示を撮る。

バファリン プレミアムDX は使わない。胃を守る成分（乾燥水酸化アルミニウムゲル）が家の抗菌薬（ミノサイクリン）の吸収を妨げるため、🔴になる（#41）。

- 「成分を読み取っています」→「家の在庫と照合しています」の2段階が出る。**約10秒かかる**
- 待っているあいだに「1段目で成分を読み、2段目で家の在庫と照らし合わせています」と話す
- 🟡 が出る（見出しの文言はAIが書くので毎回少し違う）。「根拠を見る」を開き、**成分名（アセトアミノフェン）と家のイブA錠**が出ていることを見せる
- 出典の文書名は読み上げない。いまは理由にイブプロフェンが出ると、在庫に無いワルファリンの添付文書名が付く（#42）

### ③ 在庫を変えると判定が変わる（30秒）★いちばん伝えたいこと

**A. 「もう家に無い」で見せる（#35 で入った機能。Issue #38 の N-2 が通っていれば使う）**

1. ② の判定カードのまま、「あなたの家にあるもの」のイブA錠で **「もう家に無い」** を押す
2. 約4秒で判定がやり直され、🔵 に変わる
3. 「**商品は同じです。変えたのは家の在庫だけ**」
4. **「元に戻す」** で 🟡 に戻しておく（次の来場者のため。戻し忘れても長押しの初期化で戻る）

**B. 御岳百草丸で見せる（ピッチと同じ流れ。A が使えないときもこちら）**

1. 百草丸を撮る → 🔵
2. 判定カードの下の **「買ったので在庫に入れる」** → そのまま「追加する」
3. もう一度百草丸を撮る → 🟡「家にあります」
4. 「**商品DBをどれだけ大きくしても、この違いは出せません**」

### ④ 🔴 を出す（20秒・時間があれば）

**ストナジェルサイナスEX** か **肌ラボ 極潤 薬用トラブルケア** を撮る。

- 🔴のときは、画面下の「使う前に、薬剤師・皮膚科への相談をおすすめします」を指して「**赤のときは必ず相談を勧めます**」（🔴以外でも「気になるときは〜」の一文は常に出ている）
- 「根拠を見る」の出典リンク（添付文書）を見せるなら、肌ラボのときにする。ストナジェルでは出典を取り違えることがある（#42）
- 肌ラボの🔴のあとに「買ったので在庫に入れる」を押さない。同じ化粧水を在庫に入れてから撮り直すと🟡になり、ステロイドへの注意が消える（#44）。押してしまったら長押しで初期化する

### ⑤ 締め

> 「買う前に、塗る前に、飲む前に。重ねる前に、重ねて見る。Overlai でした」

## 5. 困ったとき

| 症状 | まずやること | それでもだめなら |
| :--- | :--- | :--- |
| 「成分表示を読み取れませんでした」 | 明るい場所で、成分表示に**寄って**撮り直す。光の反射と影を避ける。箱があれば箱の平らな面を撮る | 別の商品に替える |
| 「短い時間に何度も実行されました」（429・入口の回数制限） | 30秒ほど待ってからもう一度撮る | `GUARD_MAX_REQUESTS` が入っているか確かめる |
| 「混み合っています」（429・AI側の上限） | 30秒ほど待ってからもう一度撮る | 続くなら固定応答に切り替える（下） |
| 「時間がかかりすぎたため中断しました」／「応答が返ってきませんでした」 | もう一度撮る | 回線をテザリングに切り替える |
| 「オフラインです」 | 回線をテザリングに切り替える | 固定応答に切り替える（下） |
| 何度やっても判定が返らない（AIが止まっている） | **固定応答に切り替える**：URLの末尾に `?demo=yellow` を付けて開き直す（`red` / `blue` も）。何を撮ってもその色が返る | — |
| 前の来場者の在庫が残っている | 見出しの長押し → 「戻す」 | 設定 → データ → 「見本のデータに戻す」 |
| 端末が固まった | もう1台に替える | アプリを閉じて開き直す |

**固定応答を使うときの注意**

- 判定カードの上に「これはデモ用の固定応答です」と出る。**AIの判定だと言わないこと**
- 固定応答では「もう家に無い」「買ったので在庫に入れる」は出ない。③ は見せられないので、口頭で説明する
- 判定カードだけを見せるなら `/preview?open=red` でも開ける

## 6. 聞かれそうなこと

| 質問 | 答え |
| :--- | :--- |
| 在庫はどうやって管理するの？ 使うたびに数を入れるの？ | 数は入れなくていいです。判定は「家にあるかどうか」だけで決まるので、**使い切ったときに外せば十分**です。外すのも、店頭でスキャンしたときに「もう家に無い」を押すだけ。処方薬は「何日分」を入れておくと、終わる頃に「飲み終わりましたか？」と聞きます。**在庫を直すためだけにアプリを開かなくていい**ようにしました |
| AIが間違えたら？ | 断定しません。理由には必ず成分名を出し、成分が実在しない理由は消します。出典（添付文書）へのリンクも付けます。赤のときの相談案内は、AIではなくサーバー側で必ず出しています |
| 商品DBを持つアプリとの違いは？ | 同じ商品でも、家の在庫が違えば判定が変わります（③ を見せる）。商品DBをどれだけ大きくしても出せない結果です |
| データはどこに保存しているの？ | 端末の中だけです。服薬情報は要配慮個人情報なので、預かるなら安全管理とセットでなければ無責任だと考えました |
| なぜ2段階に分けたの？ | 「読む」と「判断する」を1回でやると、読み間違いと判断の誤りを区別できないからです。分けているので、読み取った成分をユーザー自身が確かめられます |
| 処方薬はどうやって登録するの？ | いまは成分表示を撮るか、手で入力します。お薬手帳のQRコード（JAHIS）の読み取りは今後の構想です |
