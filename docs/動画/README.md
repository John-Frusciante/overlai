# ブース動画（本選 10/11・PCでループ再生）

ブースのPCで流す約90秒の紹介動画。BGMは入れず、テロップと Gemini TTS のナレーションで伝える。Remotion（React で動画を組み、mp4 に書き出す道具）で作っている。

いま入っているのは仮版で、実機の画面録画が届けば本番版になる。録画が無い場面には「素材待ち」の札が出る。

## 録画を撮る — 6本、すべて iPhone の画面収録で

本番のAIで撮る。URLに `?demo=` を付けると判定カードに「デモ用の固定応答です」と出てしまうため、付けない。撮る前に、設定 → データ →「見本のデータに戻す」で在庫をそろえておく。

| 番号 | 場面 | 撮るもの | 長さの目安 |
| :--- | :--- | :--- | :--- |
| R1 | STEP 1｜家で | マイストック →「追加」→ 薬の成分表示を撮影 → 読み取り結果 → 保存して一覧に並ぶまで | 15〜25秒 |
| R2 | STEP 2｜店で | スキャン → 商品の成分表示を撮影 → 判定カードが出るまで（待ち時間もそのまま撮ってよい） | 20〜30秒 |
| R3 | できること 1 | 🟡 の判定カード。市販の風邪薬（イブプロフェン入り）を撮り、カードをゆっくり下へスクロール | 10秒 |
| R4 | できること 2 | 🔴 の判定カード。アルコール入りの化粧水（ハダラボ薬用化粧水b など）を撮り、同じくスクロール | 10秒 |
| R5 | できること 3 | 今日のルーティン。塗る順番 → AIの一言 → 服薬チェックを付けるところまで | 15秒 |
| R6 | できること 4 | 肌質の設定で肌の状態を選び、「気になっていること」に「夜は時間がないので手早く済ませたいです。」と打つ → ルーティンに戻り、AIの一言がその悩みに沿った内容に変わるところ | 20〜30秒 |

撮るときの注意は四つある。

- 通知が映らないよう、集中モードをオンにする
- 指の動きはゆっくりにする。動画では画面を縮めて見せるので、速い操作は目で追えない
- 撮り直しは気にしなくてよい。使う区間は後から秒数で切り出せる
- R1 で登録した薬が在庫に残ると、R3・R4 の判定が変わることがある。R1 は最後に撮るか、撮り終えたら見本のデータに戻す

R3・R4 では、判定カードが出た直後（スクロールする前）に**スクリーンショットも1枚ずつ撮る**。ピッチの🟡🔴の画面をこれに差し替える。いまのピッチの画面は、ボタンが「薬剤師・皮膚科に相談する」だった頃の実機スクショのため。

R3〜R5 は、録画が間に合わなければ今の実機スクショ（静止画）のままでも成立する。優先して欲しいのは、静止画では代わりが効かない R1・R2・R6 になる。

R6 の悩みの文は、動画の左側に出す入力欄の文言と同じにしてある。別の文にするなら `src/Booth.tsx` の `NoteCard` の文言も合わせて変える。

## 録画を差し替える

1. 録画を `public/footage/` に置く（例 `public/footage/r1.mov`）
2. `src/footage.ts` の該当場面を書き換える

```ts
register: { kind: "video", src: "footage/r1.mov", aspect: 1179 / 2556, from: 2, rate: 1.5 },
```

`from` は録画の何秒目から使うか、`rate` は再生速度。R2 のAI待ちを詰めるときは `rate` を上げる。

## ナレーションを直す

原稿は `narration.json` にある。場面ごとに1文で、`scene` は `src/Booth.tsx` の場面の `id` と対応する。直したら、その場面だけ読み上げ直す。

```sh
node scripts/tts.mjs red end   # 場面を指定。何も付けなければ全部
```

読み上げは Gemini TTS（`gemini-3.8-flash-tts`、声は Zephyr）で、キーはリポジトリ直下の `.env.local` の `GEMINI_API_KEY` を使う。無料枠は1分に3回までなので、全部作り直すと4分ほどかかる。

場面の長さは、読み上げの長さに合わせて決めている。文を長くしたら、`src/Booth.tsx` のその場面の秒数も延ばす。次の場面のナレーションと重なるのを防ぐためで、目安は「話している秒数＋1.1秒」になる。

読み方の指示（「明るく」など）は本文に混ぜない。このモデルは指示まで読み上げてしまう。

## 見る・書き出す

```sh
cd docs/動画
npm install
./fonts.sh        # Noto Sans JP を取ってくる（初回だけ。9MB なのでコミットしていない）
npm run studio    # ブラウザでプレビューしながら直す
npm run render    # out/Overlai_ブース動画.mp4 に書き出す（30秒ほど）
```

構成（場面の順番・長さ・テロップ）は `src/Booth.tsx`、場面ごとの見た目は `src/scenes.tsx` にある。色と文言はピッチ（`docs/ピッチ/build.py`）とそろえている。
